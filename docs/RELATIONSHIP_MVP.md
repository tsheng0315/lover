# 亲密关系模式（MVP）

本分支将 Jev 的判断层用于亲密关系中的文字沟通提醒。它只提示当前对话里可观察到的互动信号与张力，**不是**心理诊断、关系评判或事实裁决。

## 当前输出

- 互动信号：表达受伤、寻求连接、边界冲突、防御升级、回避或冷却、修复尝试、日常互动。
- 对话张力：0--9 的保守估计。它描述此刻是否适合放慢沟通，不能用于判断谁有错或给对方贴标签。
- 温和建议：先确认感受、设定可执行边界、暂停并约定回谈时间等用户可选动作。
- 关系理解卡片：一次生成一张按语意组织的分层阅读，而非固定清单；它按需要组合用户空间、表面表达、未被听见的需要、可能的感受与想法、用户反应、语言线索、可能的听感，以及一条可选的温和表达。

## 明确不做的事

- 不将单段聊天判定为操控、人格障碍、依恋类型或虐待事实。
- 不监听或录制通话；语音分析将只接受用户主动导入且有权处理的音频。
- 不自动回复、自动发送或替用户做关系决定。

## 下一个迭代

为每个互动信号返回可复核的文本证据与不确定性说明，并允许用户纠正结果；高张力时改为“先暂停”的界面，而非生成更多回复。
